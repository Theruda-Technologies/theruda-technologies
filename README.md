# Theruda Technologies

Portfolio website for **Theruda Technologies** — a tech studio offering Software Development, UI/UX Design, AI Solutions, and Graphics Design.

## Stack

- [Next.js](https://nextjs.org) (App Router)
- TypeScript
- Tailwind CSS v4 with CSS custom properties (theme tokens)

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Design tokens

Colors and brand gradient live in `src/app/globals.css` under `:root`. Adjust those variables to retheme the site without hunting through components.

## Scripts

| Command       | Description              |
| ------------- | ------------------------ |
| `npm run dev` | Local development server |
| `npm run build` | Production build       |
| `npm run start` | Serve production build |
| `npm run lint`  | Run ESLint             |
